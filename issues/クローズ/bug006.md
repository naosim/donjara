# bug006: 1局終わった後にすぐに次の対局が始まってしまう
ステータス:解決済み
内容: 1局終わった後にすぐに次の対局が始まってしまう。ユーザが「次の対局へ進む」ボタンを押したら次に進んでほしい。
修正内容: 局終了後に「▶️ 次の対局へ進む」ボタンを表示し、押されるまで次局を開始しないよう game.js を修正。
- `endRound` は結果を表示後、`waitForNextRound()` でローカル人間のボタン押下を待つ（自動進行の `sleep(2000)` を廃止）
- AIモード: 人間がボタンを押したら次局開始。最終局（第4局）はボタンなしでゲームオーバー画面へ
- PvP: 親機と子機（相手）の**両方**がボタンを押すまで次局を開始しない。子機の押下は `{t:'next'}` で親機へ通知（`guestNextReady` / `waitForGuestNext`）。子機は押下後に「準備OK」表示、2重送信防止
- 子機側は `phase:'roundEnd'` の同期を受け取ると残っていた操作待ちを解除し、次局（phase:'play'）の同期でフラグをリセット
- エンジンテスト（AI4局・PvPホスト両者確認・子機先押し）とDOMモック（ボタン表示/送信パケット）で検証済み

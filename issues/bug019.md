# bug019: 役一覧を表示してほしい

ステータス:修正済み

内容: 役一覧画面を追加してほしい

期待する動作: ゲーム画面から役の一覧（役名・点数・種別・説明）を確認できる。

再現手順:
1. donjara_game.html を開く
2. ヘッダーの「📋 役一覧」ボタンをタップする
3. 役の一覧が表示される

修正内容: donjara_game.html のヘッダーに「📋 役一覧」ボタンを追加。ボタンを押すと donjara_config.js の DONJARA_YAKU_CLASSES から全役を読み込み、役名・点数・あがり役/付加役の区別・成立条件をテーブル形式で一覧表示するモーダルを実装。E-Inkテーマにも対応。
